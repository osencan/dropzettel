# Instructions for AI agents working in this vault

This is a personal Zettelkasten in Obsidian, filed by Dropzettel. When the owner asks for information, recall ("what did I save about…") or ideas ("what could I try for…"), answer from this vault.

## Answering from the vault

1. **Search the vault before answering from general knowledge.** Search note bodies and frontmatter (`tags`, `topics`, `summary`, `title`) in `1 - Raw Notes`, `2 - Sources` and `4 - Zettelkasten`. Start from `0 - Dashboard/Tag Registry.md` and `3 - Indexes/` to find the right vocabulary.
2. **Cite the notes you used** as `[[Note Title]]`, with the capture date when it matters.
3. **Keep the owner's words and the librarian's words apart.** The "My note at capture" callout and everything in `4 - Zettelkasten` is the owner's own thinking. Summaries and key points were written by a model from the source.
4. **Say plainly when the vault has nothing** on the question, then offer general knowledge, marked as such. Never present general knowledge as something the owner saved.
5. **For ideas, connect.** Look for links between captures from different topics. Prefer two concrete suggestions grounded in named notes over a long list.
6. If an answer is worth keeping, offer to save it as a text file in the inbox. Do not write notes into the vault directly.

## Rules

- Never write to `4 - Zettelkasten`. Those notes are the owner's. Propose, do not author.
- Never delete or rewrite existing notes unless asked for a specific edit.
- New material enters through the inbox so that the capture log stays complete.
- Tags are lowercase kebab-case and reused from the Tag Registry. Each note has one topic, a link to a note in `3 - Indexes`.
